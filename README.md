# 🎲 RITESH Exploits Ludo

A fun multiplayer Ludo dice game with 2/3/4 player support, Hindi galis (for fun), sound effects, and animations.

## Features
- ✅ 2, 3, or 4 player support
- ✅ Target: 30 points
- ✅ 100+ Hindi galis (spoken on each roll)
- ✅ Funny sound effects
- ✅ Emoji burst animations
- ✅ Winner announcement with gali
- ✅ Sound on/off toggle
- ✅ Mobile responsive

## Run Locally
```bash
pip install -r requirements.txt
python app.py
